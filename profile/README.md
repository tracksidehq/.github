<h1 align="center">Paralaxe</h1>

<p align="center">
  <b>Run AI agents side by side, under your rules.</b><br>
  A desktop workbench for AI coding agents: compare them, set the policy, audit every action.
</p>

<p align="center">
  <a href="https://paralaxehq.vercel.app">Website</a> ·
  <b>Coming soon</b> · open source under Apache-2.0
</p>

---

**What it is.** Real terminals in tabs and split panes, one agent in each. A policy file decides what every agent may do, tool by tool and path by path. Every decision is written to a hash-chained audit trail before it takes effect. Everything runs on your machine: no account, no telemetry.

**Where it stands.** In active development, macOS first. The source will be published here with the first public build.

- Compare: the same prompt to every pane, with Claude Code, Codex and local models.
- Govern: an MCP gateway (allow, ask, deny) and an agent hook for shell and files.
- Audit: a trail you can verify and export.

Watch this organization to be notified when the repository opens.
